## Ski poles

**Job:** thousands of km on BC track, deep snow, pulk side-load. Favour **durable** over race carbon.

### What to look for

| Feature | Why |
|---------|-----|
| **Large powder basket** (~9–10 cm) | Soft snow — small baskets sink |
| **Screw-on baskets** | Carry **2 spares** |
| **7075 alu or burly carbon** | Pulk torque; alu bends, carbon can shatter |
| **Length** | BC: **~35–40 cm below height**; with pulk often **145–155 cm** for 175–185 cm skier — verify on snow |
| **Long EVA grip** | Multiple hand positions |
| **Carbide tip** | Ice, wind crust |
| **Repair** | Pole sleeve + **Åsnes flex tip** |

### Recommended

| Pole | Type | Weight (pair) | Comment |
|------|------|---------------|---------|
| **Åsnes Ingstad Alloy** ★ | Fixed 130–160 cm | ~450 g @ 145 | **Default** — large Hypalon basket; matches Ingstad/Outback |
| **Start Aluminium** | Adjustable ~135–180 | ~550–600 g | Expedition standard; if unsure of length |
| **Swix Quantum 4** | Fixed/adj. | varies | Swap to largest powder basket |
| **Black Diamond Expedition 3** | 3-piece 85–125 cm | ~520 g | Check max length fits your height |

**Skip:** race carbon, trekking poles without ski baskets, tiny 5 cm baskets.

### Sizing (Ingstad Alloy)

| Height (boots on snow) | Start with |
|------------------------|------------|
| ~165–170 cm | **140–145 cm** |
| ~175–180 cm | **145–150 cm** |
| ~185–190 cm | **150–155 cm** |

### Accessories

| Item | Qty |
|------|-----|
| Spare large baskets | 2 |
| Åsnes flex tip | 1 |
| Pole repair sleeve (~14 mm) | 1 |

**Verdict:** **Åsnes Ingstad Alloy** in the right fixed length — or **Start Aluminium** if you want adjustability.

## Climbing skins

**Status:** Both pairs **no working glue** — not trip-ready until **full reglue** or **replace**.

| Set | Role (after fix) |
|-----|----------------|
| **Short Åsnes** | **Primary** — Skinlock on Ingstad; fishscale + short skin = most days |
| **Long old** | **Padjelanta / Lappjord** sustained climbs — not all-day on flats |

### When to use what

| Terrain | Skins |
|---------|-------|
| Flats, wind crust, scooter tracks | **Fishscale only** |
| Rolling fjäll, short climbs | **Short Åsnes** |
| Padjelanta (D45–51), long climb | **Short** first; **long** if slipping |
| Lappjord haul | **Long** |
| Deep cold, glue won’t stick | Warm skins in jacket; fishscale; wax backup |

### Fix glue — choose one

| Option | What | Comment |
|--------|------|---------|
| **A — Reglue both** ★ | Strip + full reglue | Cheapest if fabric OK — autumn 2026 |
| **B — New short only** | Åsnes X-Skin 45/58 mm | Reglue long if width fits |
| **C — Replace both** | New short + full-length | If long fabric worn |
| **D — No skins** | Wax only | **Not recommended** for Padjelanta + pulk |

**Timeline:** reglue → cure 24–72 h → freeze test → shakedown with **loaded pulk** on a climb.

### Carry (once glued)

| Item | Qty |
|------|-----|
| Short Åsnes | 1 pair |
| Long old | 1 pair (pulk) |
| Skin wax | 1 stick |
| Glue tube | 1 small (field patch only) |
| Spare ski strap | 1 |

**Verdict:** **Priority fix** before Feb 2027 — do not start with dead glue.

## Pulk — Jemtlander 14

| | **Jemtlander 14 — 200 L** |
|---|---------------------------|
| **Size** | 144 × 50 cm outer; **200 L** bag |
| **Rigged weight** | ~**5.3 kg** |
| **Strengths** | Course-stable; good on **tracks / KL / scooter corridors** |
| **Limits** | Shorter than 1.7 m sleds — Jemtlander recommends **17** for heavy off-trail |

**Fit for Bandet:** **Good** for main line — dense packs (~24 cm height), 10-day resupply rhythm. Padjelanta/Lappjord = kick-turns regardless of sled.

**Packing:** heavy **low and centred**; fuel upright; dry bags inside; **sleep kit in Sleeper**, not main bag.

**Upgrade only if** shakedown shows constant grounding in deep soft snow → **Jemtlander 17**.

## Navigation, comms & power

### Devices

| Device | Role |
|--------|------|
| **GPSMAP 68i** | Primary GPS + inReach (with plan) |
| **Fairphone** | **OsmAnd+** offline + GPX at camp |
| **inReach Mini 3+** | Optional if 68i not on body daily |
| **2× 20k power banks** | Primary recharge strategy |
| **Solar 15–28 W** | Optional Mar–Apr supplement only |

### inReach Mini 3+ vs 68i

| | **68i** | **Mini 3+** |
|---|---------|-------------|
| Navigation | **Excellent** — buttons, AA power | Basic; mainly messaging |
| Satellite | inReach (with plan) | inReach (with plan) |
| Carry | Often pulk — **SOS useless if buried** | **Inside jacket** |
| Battery | **AA lithium** — better in cold | Li-ion — needs USB |

1. Confirm **68i inReach plan** before buying Mini.  
2. If 68i **on body** daily: Mini is **optional** redundancy.  
3. If 68i **in pulk**: get Mini **or** belt pouch for 68i.  
4. One subscription usually = **one** active inReach unit.

### OsmAnd+ setup

1. Download Sweden north + Norway strips (**5–15 GB**).  
2. Import **`tracks/2027.GPX`**.  
3. Contour lines on; high-contrast winter profile.  
4. Shakedown: one day **68i only**, one **phone only**.

### Map app alternatives

| App | Role |
|-----|------|
| **OsmAnd** ★ | Primary phone nav |
| **Organic Maps** | Tiny lightweight backup |
| **Paper Fjällkarta** | Whiteout / battery death |
| **Gaia / Avenza** | Skip as primary for full route |

**Hierarchy:** **68i** (skiing) → **OsmAnd** (stopped) → **paper + compass**.

### Power

| Item | Qty | Notes |
|------|-----|-------|
| Power bank 20k USB-C PD | **2** | Warm in jacket before use |
| AA lithium | **12–16** | 68i — not alkaline in Feb |
| Wall charger 30–45 W | 1 | Resupply nights |
| Solar 15–28 W | 0–1 | **Feb poor**; marginal Mar–Apr |

Charge at every **★** resupply; sleep with phone + one bank in bag foot on cold tent nights.

## Tent — Nallo 3GT & upgrades

### Hilleberg labels

| Label | Fabric | Your tent |
|-------|--------|-----------|
| **Black** | Kerlon 1800 — harshest | Upgrade path |
| **Red** | Kerlon 1200 — 4-season | **Nallo 3GT** ✓ |
| **Yellow** | 3-season | Skip for Feb |

**Nallo 3GT:** ~**3.1 kg** packed · huge **GT vestibule** · not freestanding · tunnel must face wind.

**Verdict:** **Usable** for 65 days if pitching/stakes are solid. **2–3 winter shakedowns** before buying Black Label.

### Black Label candidates

| Tent | Packed | vs Nallo | Comment |
|------|--------|----------|---------|
| **Nammatj 2 GT** ★ | 3.8 kg | +~700 g | Same tunnel+GT logic, Kerlon 1800 |
| **Nammatj 3 GT** | 4.1 kg | +~1 kg | More space |
| **Staika** | 4.0 kg | +~900 g | Freestanding; less single workshop vestibule |
| **Tarra** | 4.3 kg | +~1.2 kg | Strongest dome; smaller vestibule |
| **Saivo 3** | 5.6 kg | +2.5 kg | **Too heavy** for solo pulk |

### Red Label lighter (not Black)

| Tent | Packed | Comment |
|------|--------|---------|
| **Nallo 2 GT** | ~2.7 kg | −400 g; same Red fabric |
| **Allak 2** | ~3.3 kg | Freestanding; smaller vestibule |

### Decision guide

| Shakedown shows… | Lean toward |
|------------------|-------------|
| Nallo fine in wind; like vestibule | **Keep Nallo 3GT** |
| Want expedition margin | **Nammatj 2 GT** (Black) |
| Stakes won’t hold / crust | **Staika** or **Tarra** (freestanding) |
| Save weight, accept Red limits | **Nallo 2 GT** |

### Chosen pad plan

| Phase | Days | Pad in Sleeper |
|-------|------|----------------|
| **Start → Abisko** | 1–62 | **Exped Ultra 7R** |

**At Abisko switch:** repack Sleeper with XLite; ship Ultra home or carry as backup.

**Shakedown:** Ultra 7R + bag at **−15 °C** on snow; test XLite once for April decision.

## Socks & VBL

**Buy 4–5 new heavy merino ski socks** (over-calf, medium–heavy) + **1–2 camp** pairs. Try in **Outback** with any VBL in shop.

### VBL optional

| | VBL + merino | Merino rotation only |
|---|--------------|----------------------|
| **Pros** | Drier boots over weeks; steady −15…−30 °C | Simple; easier blister care |
| **Cons** | Clammy; blisters if wrinkled | Wet socks freeze; must dry daily |

**Recommendation:** Start **without VBL** on shakedown. Try VBL only if feet stay wet **3+ days**. **One pair** max if adopted.
